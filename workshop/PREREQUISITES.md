# Agentic Workshop: participant prerequisites

Build two AI agents and a coordinating workflow in Microsoft Foundry, guided
step by step by Workshop Coach in the GitHub Copilot app. No prior agent
development experience is required.

## Before you attend

1. **Install and sign in to the [GitHub Copilot app](https://github.com/features/ai/github-app).**
   Use a GitHub account with the required Copilot entitlement or your
   organization's approved access arrangement.
2. **Install [Git](https://git-scm.com/install/).**
   Follow your organization's installation policy; Git command knowledge is
   not required.
3. **Get the workshop repository link and revision from your facilitator.**
   Open that revision as a project in the GitHub Copilot app.
4. **Verify your assigned [Microsoft Foundry Project](https://ai.azure.com/).**
   Sign in with the account specified by your facilitator and confirm you can
   access your dedicated project. If it is missing or inaccessible, contact
   the facilitator; do not create another project.

**No upfront Python, Foundry packages, Azure CLI, Azure Developer CLI, or
VS Code installation is required.** The coach introduces additional tools when
needed. Use only public or synthetic practice data; never share credentials.
